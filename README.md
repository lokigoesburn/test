# toybox

A throwaway toy codebase. It exists for exactly one purpose: a sealed
prototype test. Nothing here is real, nothing here matters, and nothing
here connects to anything else.

## Layout

- `toybox.py` — tiny string helpers.
- `test_toybox.py` — tests for the helpers.

## Open task

`slugify()` in `toybox.py` is a stub that raises `NotImplementedError`.
Its tests in `test_toybox.py` describe what it should do.
